## Getting Started with Cloud

<Steps>
  <Step title="Sign up for Autumn">
    Create your account at [app.useautumn.com](https://app.useautumn.com)
  </Step>
  
  <Step title="Create your first product">
    In the dashboard, create a product and define your pricing:
    - Set base subscription price
    - Add features with limits
    - Configure billing intervals
  </Step>
  
  <Step title="Get your API key">
    Navigate to **Settings** → **API Keys** and create a secret key. Add it to your environment:
    
    ```bash .env
    AUTUMN_SECRET_KEY=am_sk_test_xxxxx
    ```
  </Step>
  
  <Step title="Install the SDK">
    Choose your preferred package manager:
    
    <CodeGroup>
    ```bash npm
    npm install autumn-js
    ```
    
    ```bash bun
    bun add autumn-js
    ```
    
    ```bash pnpm
    pnpm add autumn-js
    ```
    
    ```bash yarn
    yarn add autumn-js
    ```
    </CodeGroup>
  </Step>
</Steps>

## Integration Guide

Autumn provides framework-specific handlers for seamless integration:

<Tabs>
  <Tab title="Next.js">
    ### Next.js App Router
    
    Create an API route handler:
    
    ```typescript app/api/autumn/[...all]/route.ts
    import { autumnHandler } from "autumn-js/next";
    
    export const { GET, POST } = autumnHandler({
      identify: async (request) => {
        // Get user/org from your auth provider
        const session = await auth.api.getSession({ 
          headers: request.headers 
        });
        
        return {
          customerId: session?.user.id,
          customerData: {
            name: session?.user.name,
            email: session?.user.email,
          },
        };
      },
    });
    ```
    
    Add the provider to your layout:
    
    ```tsx app/layout.tsx
    import { AutumnProvider } from "autumn-js/react";
    
    export default function RootLayout({ children }) {
      return (
        <html>
          <body>
            <AutumnProvider>
              {children}
            </AutumnProvider>
          </body>
        </html>
      );
    }
    ```
  </Tab>
  
  <Tab title="React Router">
    ### React Router Setup
    
    Create the Autumn route:
    
    ```typescript app/routes/api.autumn.tsx
    import { autumnHandler } from "autumn-js/react-router";
    
    export const { loader, action } = autumnHandler({
      identify: async (args) => {
        const session = await auth.api.getSession({ 
          headers: args.request.headers 
        });
        
        return {
          customerId: session?.user.id,
          customerData: { 
            name: session?.user.name, 
            email: session?.user.email 
          },
        };
      },
    });
    ```
    
    Add to routes.ts:
    
    ```typescript routes.ts
    route("api/autumn/*", "routes/api.autumn.tsx")
    ```
    
    Wrap your app with the provider:
    
    ```tsx app/root.tsx
    import { AutumnProvider } from "autumn-js/react";
    
    export default function App() {
      return (
        <AutumnProvider>
          <Outlet />
        </AutumnProvider>
      );
    }
    ```
  </Tab>
  
  <Tab title="Express">
    ### Express Setup
    
    ```typescript server.js
    import express from "express";
    import { autumnHandler } from "autumn-js/express";
    
    const app = express();
    
    app.use(express.json()); // Must be before autumnHandler
    
    app.use("/api/autumn", autumnHandler({
      identify: async (req) => {
        const session = await auth.api.getSession({ 
          headers: fromNodeHeaders(req.headers) 
        });
        
        return {
          customerId: session?.user.id,
          customerData: { 
            name: session?.user.name, 
            email: session?.user.email 
          },
        };
      },
    }));
    ```
    
    For React frontend, add the provider:
    
    ```tsx
    import { AutumnProvider } from "autumn-js/react";
    
    // If backend is on different URL
    <AutumnProvider backendUrl={process.env.BACKEND_URL}>
      <App />
    </AutumnProvider>
    ```
  </Tab>
  
  <Tab title="Backend Only">
    ### Backend Only Setup
    
    For server-side only implementations:
    
    <CodeGroup>
    ```typescript Node.js
    import { Autumn } from "autumn-js";
    
    const autumn = new Autumn({
      secretKey: process.env.AUTUMN_SECRET_KEY,
    });
    
    // Create or get customer
    const { data } = await autumn.customers.create({
      id: "user_123",
      name: "John Doe",
      email: "john@example.com",
    });
    ```
    
    ```python Python
    from autumn import Autumn
    
    autumn = Autumn('am_sk_test_xxx')
    
    # Create or get customer
    customer = await autumn.customers.create(
        id="user_123",
        name="John Doe",
        email="john@example.com"
    )
    ```
    
    ```bash cURL
    curl -X POST https://api.useautumn.com/customers \
      -H "Authorization: Bearer am_sk_test_xxx" \
      -H "Content-Type: application/json" \
      -d '{
        "id": "user_123",
        "name": "John Doe",
        "email": "john@example.com"
      }'
    ```
    </CodeGroup>
  </Tab>
</Tabs>

## Using the Core Functions

Once integrated, use Autumn's three core functions:

### Check Access

Check if a customer can access a feature:

```typescript
const { check } = useAutumn();

const { data } = await check({ featureId: "ai_tokens" });

if (!data.allowed) {
  alert("AI limit reached - upgrade to continue");
}
```

### Attach Plans

Handle purchases and plan changes:

```tsx
const { attach } = useAutumn();

<button
  onClick={async () => {
    await attach({ productId: "pro" });
  }}
>
  Upgrade to Pro
</button>
```

### Track Usage

Record usage events:

```typescript
const { track } = useAutumn();

const response = await generateAI();

await track({
  featureId: "ai_tokens",
  value: response.tokensUsed
});
```
