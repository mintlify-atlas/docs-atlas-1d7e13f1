### What to Include in Your Email

To help us assist you quickly, please include:

<AccordionGroup>
  <Accordion title="Subject Line" icon="heading">
    Clear, descriptive subject line (e.g., "API returns 500 on /check endpoint" instead of "Help needed")
  </Accordion>

  <Accordion title="Account Information" icon="user">
    - Your organization ID (if applicable)
    - Environment (test/live)
    - Self-hosted or cloud version
  </Accordion>

  <Accordion title="Issue Details" icon="list">
    - What you're trying to do
    - What's happening vs. what you expected
    - Steps to reproduce
    - Error messages or logs
  </Accordion>

  <Accordion title="Code Snippets" icon="code">
    Include relevant code (sanitize API keys!):
    ```typescript
    const response = await check({ 
      featureId: 'ai_tokens',
      customerId: 'cus_123' 
    });
    // Returns 500 error
    ```
  </Accordion>
</AccordionGroup>

### Creating a Good Issue

<Tabs>
  <Tab title="Bug Report">
    ```markdown
    ## Description
    Brief description of the bug
    
    ## Steps to Reproduce
    1. Call `/v1/check` with feature_id "ai_tokens"
    2. Observe 500 error response
    
    ## Expected Behavior
    Should return { allowed: true/false }
    
    ## Actual Behavior
    Returns 500 Internal Server Error
    
    ## Environment
    - Autumn version: Self-hosted main branch
    - Node version: 20.x
    - OS: macOS 14
    
    ## Additional Context
    Error logs, screenshots, etc.
    ```
  </Tab>
  
  <Tab title="Feature Request">
    ```markdown
    ## Feature Description
    Clear description of the proposed feature
    
    ## Use Case
    Why is this feature needed? What problem does it solve?
    
    ## Proposed Solution
    How you envision this working
    
    ## Alternatives Considered
    Other approaches you've thought about
    
    ## Additional Context
    Any other relevant information
    ```
  </Tab>
</Tabs>

## Common Issues

Quick solutions to common problems:

<AccordionGroup>
  <Accordion title="API Key Authentication Failing" icon="key">
    **Check:**
    - API key includes full prefix (`am_sk_test_` or `am_sk_live_`)
    - Authorization header format: `Bearer your_key_here`
    - Key hasn't been revoked
    - Using correct environment (test vs live)
    
    See [Authentication](/resources/authentication) for details.
  </Accordion>

  <Accordion title="Rate Limit Exceeded" icon="gauge">
    **Solutions:**
    - Implement exponential backoff
    - Cache frequently accessed data
    - Batch operations when possible
    - Contact us for higher limits
    
    See [Rate Limits](/resources/rate-limits) for details.
  </Accordion>

  <Accordion title="Database Connection Issues" icon="database">
    **Check:**
    - `DATABASE_URL` in `server/.env` is correct
    - Database is accessible from your environment
    - Tables have been created with `bun db:push`
    - Firewall rules allow connections
  </Accordion>

  <Accordion title="Webhook Not Receiving Events" icon="webhook">
    **Check:**
    - Localtunnel is running (in Docker Compose)
    - `STRIPE_WEBHOOK_URL` is set correctly
    - Stripe webhook endpoint is registered
    - Webhook signature verification is working
  </Accordion>
</AccordionGroup>
