# Attach Product

Enables a product for a customer and processes payment if their payment method is already on file.

## When to Use

Use this when the customer already has a payment method saved. For new customers without payment info, use `checkout` instead.

## Authentication

Requires a valid API key passed in the `Authorization` header:

```bash
Authorization: Bearer YOUR_API_KEY
```

## Request Body

<ParamField body="customer_id" type="string" required>
  The ID of the customer
  
  **Example:** `cus_123`
</ParamField>

<ParamField body="product_id" type="string">
  The ID of the product to attach
  
  **Example:** `pro_plan`
  
  **Note:** Either `product_id` or `product_ids` must be provided
</ParamField>

<ParamField body="product_ids" type="string[]">
  Array of product IDs to attach multiple products at once
  
  **Example:** `["pro_plan", "addon_storage"]`
  
  **Note:** Either `product_id` or `product_ids` must be provided. Cannot contain duplicates.
</ParamField>

<ParamField body="entity_id" type="string">
  The ID of the entity (optional, for entity-scoped products)
  
  **Example:** `entity_123`
</ParamField>

<ParamField body="customer_data" type="object">
  Additional customer properties. These will be used to create or update the customer if they don't exist or their properties are not already set.
  
  <ParamField body="customer_data.name" type="string">
    Customer's name
  </ParamField>
  
  <ParamField body="customer_data.email" type="string">
    Customer's email address
  </ParamField>
  
  <ParamField body="customer_data.fingerprint" type="string">
    Unique identifier (eg, serial number) to detect duplicate customers and prevent free trial abuse
  </ParamField>
  
  <ParamField body="customer_data.metadata" type="object">
    Additional metadata for the customer
  </ParamField>
  
  <ParamField body="customer_data.stripe_id" type="string">
    Stripe customer ID if you already have one
  </ParamField>
  
  <ParamField body="customer_data.send_email_receipts" type="boolean">
    Whether to send email receipts to this customer
  </ParamField>
</ParamField>

<ParamField body="entity_data" type="object">
  Additional entity properties. These will be used to create the entity if it doesn't exist.
</ParamField>

<ParamField body="options" type="array">
  Feature options for configuring specific features in the product
</ParamField>

<ParamField body="free_trial" type="boolean | object">
  Whether to start a free trial. Can be a boolean or a free trial configuration object.
  
  **Example:** `true` or `{ duration: 14, interval: "day" }`
</ParamField>

<ParamField body="success_url" type="string">
  URL to redirect to after successful payment (if checkout is required)
  
  **Example:** `https://example.com/success`
</ParamField>

<ParamField body="force_checkout" type="boolean">
  Force creation of a checkout session even if payment method exists
  
  **Default:** `false`
</ParamField>

<ParamField body="checkout_session_params" type="object">
  Additional parameters to pass to the payment processor's checkout session
</ParamField>

<ParamField body="reward" type="string | string[]">
  Reward ID(s) to grant upon successful attachment
</ParamField>

<ParamField body="invoice" type="boolean">
  Whether to create an invoice for this attachment
</ParamField>

<ParamField body="setup_payment" type="boolean">
  Whether to setup payment method during checkout
</ParamField>

<ParamField body="new_billing_subscription" type="boolean">
  Whether to create a new billing subscription
</ParamField>

<ParamField body="is_custom" type="boolean">
  Whether this is a custom product (requires `items` field)
</ParamField>

<ParamField body="items" type="array">
  Product items for custom products (only valid when `is_custom` is true)
</ParamField>

<ParamField body="invoice_only" type="boolean">
  Whether to only create an invoice without processing payment
</ParamField>

<ParamField body="metadata" type="object">
  Additional metadata to attach to the subscription
</ParamField>

<ParamField body="billing_cycle_anchor" type="number">
  Unix timestamp for when the billing cycle should start
</ParamField>

<ParamField body="enable_product_immediately" type="boolean">
  Whether to enable the product immediately or wait for payment
</ParamField>

<ParamField body="finalize_invoice" type="boolean">
  Whether to finalize the invoice immediately
</ParamField>

## Response

<ResponseField name="success" type="boolean" required>
  Whether the attachment was successful
</ResponseField>

<ResponseField name="customer_id" type="string" required>
  The ID of the customer
</ResponseField>

<ResponseField name="product_ids" type="string[]" required>
  Array of product IDs that were attached
</ResponseField>

<ResponseField name="code" type="string" required>
  Response code indicating the result
</ResponseField>

<ResponseField name="message" type="string" required>
  Human-readable message describing the result
</ResponseField>

<ResponseField name="checkout_url" type="string">
  URL to redirect the customer to for payment (if payment is required)
</ResponseField>

<ResponseField name="invoice" type="object">
  Invoice object if an invoice was created
</ResponseField>

## Notes

- If the customer doesn't have a payment method on file and payment is required, a `checkout_url` will be returned
- You can attach multiple products at once using the `product_ids` array
- Use `customer_data` to create or update customer information atomically with the attachment
- The `free_trial` parameter can trigger trial periods as configured in your product settings
