---
title: 'Create Balance'
openapi: 'POST /balances/create'
---

Create a new balance for a specific feature for a customer. Balances track the quantity of a feature a customer has access to.

## Request Body

<ParamField path="feature_id" type="string" required>
  The feature ID to create the balance for
</ParamField>

<ParamField path="customer_id" type="string" required>
  The customer ID to assign the balance to
</ParamField>

<ParamField path="entity_id" type="string">
  Entity ID for entity-scoped balances. If provided, customer_id must also be provided.
</ParamField>

<ParamField path="included" type="number">
  The initial balance amount to grant. Required for metered features unless unlimited is true.
</ParamField>

<ParamField path="unlimited" type="boolean">
  Whether the balance is unlimited. Cannot be combined with included for metered features.
</ParamField>

<ParamField path="reset" type="object">
  Reset configuration for the balance. Cannot be combined with unlimited.
  
  <Expandable title="Reset Object">
    <ParamField path="interval" type="enum" required>
      Reset interval: `day`, `week`, `month`, `year`, `billing_period`
    </ParamField>
    
    <ParamField path="interval_count" type="number">
      Number of intervals between resets (e.g., 2 for every 2 months)
    </ParamField>
  </Expandable>
</ParamField>

<ParamField path="expires_at" type="number">
  Unix timestamp (milliseconds) when the balance expires
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  Indicates whether the balance was created successfully
</ResponseField>

## Validation Rules

- For **boolean** features: Cannot specify `included`, `unlimited`, or `reset`
- For **metered** features: Must provide either `included` or set `unlimited` to true, but not both
- `unlimited` cannot be combined with `reset`
- `entity_id` requires `customer_id` to be provided

## Example

```json Request - Fixed Balance
{
  "feature_id": "api_calls",
  "customer_id": "cus_123",
  "included": 1000
}
```

```json Request - Unlimited Balance
{
  "feature_id": "api_calls",
  "customer_id": "cus_123",
  "unlimited": true
}
```

```json Request - Resetting Balance
{
  "feature_id": "api_calls",
  "customer_id": "cus_123",
  "included": 1000,
  "reset": {
    "interval": "month",
    "interval_count": 1
  }
}
```

```json Response
{
  "success": true
}
```
